# lintel 格子清单：来源程序能在刘海上放什么

Date: 2026-09-19 · 读的是 `8b29839` 之后的代码（`Sources/LintelCore/Activity.swift`、`Ordering.swift`，`Sources/LintelUI/StageView.swift`、`Blocks.swift`、`DetailPanel.swift`、`StageController.swift`）。

- 字段的**类型与校验上限**（超了就拒收）见 `activity-v1.md`（由 `lintel schema` 生成）。
- 本页写的是另一层：**每个字段显示在屏幕哪里、实际放得下多少、放不下时怎么办**。校验上限往往远大于放得下的量（例：右翼校验上限 64 字，屏幕上约 6 个汉字）。
- 真屏样子见 `docs/verification/2026-09-19-awt-on-lintel/`（两个来源同时在）与 `docs/verification/2026-09-18-f2-closed/`（面板）。
- 「约 N 字」都是按字号与宽度算的近似值，没有逐字实测；定稿前用 `tools/shoot_scenes.py` 拍一张核对。

**一句话**：内容由来源写，lintel 一行都不用改；要一种这里没有的格子，lintel 就加一种通用格子，所有来源都能用。

## 0. lintel 定的、对所有来源都一样的规则

- **同一时刻最多两件事**：主项占两翼，第二项进胶囊。
- **谁是主项**（`Ordering.focus`，先满足的先上；刚弹出的那一件先钉住）：
  1. 异常（`rank: anomaly`）
  2. 等你（`waiting`）
  3. 刚发生的事（`event`）
  4. 没看过且自标不一致（`flagged`）
  5. 没看过
  6. 最近有动静（`activityAt`）
- **谁进胶囊**：主项以外，依次是异常、等你、刚发生的事、正在进行（`inProgress`），最后是有胶囊内容的。
- 主项无话可说（右翼缩回）而另一件有话说：把那件提成主项。
- **主动弹出**：只在事件到达、而且这种事件登记时标了 `attention` 的时候；弹出精简版，6 秒后收起（鼠标停在上面就不收）。没标 `attention` 的事件只刷新内容；登记时给了 `dismiss=秒` 的，到达时刘海若正展开着，就停这么多秒再收起（许愿柳的「打断一轮」）。
- **看过**：lintel 记每个活动的 `revision` 你看过没有。`labelUntilSeen` / `pillUntilSeen` 为真时，看过就缩回。
- **结束的活动**：`stale` 的不上刘海，只在面板里；面板只列今天关的，更早的折成一行。
- **两个及以上来源同时在时**：收起态左翼与胶囊画来源的身份——登记了 `--shape`（`bracket` 括号形）与 `--tint`（身份色）就画形状，不加容器；没登记的画识别字（`--initial`）的小圆标。左翼的状态图标也随形状走：括号形来源画括号里的状态符号，不画许愿柳的外圈弧与四点。
- **lintel 不强制「一个来源一个活动」**：一个来源写 3 个活动，就是 3 件事互相竞争（09-19 实拍：AWT 的第二张卡占了胶囊）。这一条要来源自己守。

## 1. 收起态（常驻，一眼要看的）

| 格子 | 字段 | 放得下 | 备注 |
|---|---|---|---|
| 左翼圆心 | `status.center` | 9 选 1 | live 扇形（写得越近越满）· waiting 问号 · done 对勾 · flagged 橙色叹号 · broken 红色叹号 · withdrawn 回退箭头 · idle 横线 · superseded 菱形 ◇ · assumed 虚线圆 ◌ |
| 左翼外圈 | `status.ringRemaining` | 0…1 | 像电量，剩 20% 变橙、10% 变红 |
| 左翼底部四点 | ——（lintel 数的） | 0–4 | 同一来源里开着且在跑的活动数 |
| 左翼计时 | `status.clock` | 一个数 | `live` 每秒走（收起态不滚动）· `ago` 写「刚刚 / 12 分 / 3 时」· `frozen` 划线 |
| 身份 | 登记的 `mark.shape` + `mark.tint`，没有就 `initial` | 一个形状或 1 个字 | 只在两个来源同时在时画 |
| **右翼** | `label.text` + `label.tone` | **约 6 个汉字**；最多约 9 个汉字 / 14 个英文字母，再长截断 | 你最先读到的那句；`labelUntilSeen` |
| 胶囊（只在作为第二项时） | `pill.symbol` / `dot` / `tint` / `title` / `clockSince` | 一个符号加约 3 个汉字或一个计时，宽 ≤120pt | 有计时时不闪（`pulse` 只在没有计时时生效）；悬停时长出 `pill.preview`（约 130pt） |

## 2. 弹出（精简版：事件标了 `attention` 时主动弹 6 秒）

| 格子 | 字段 | 放得下 |
|---|---|---|
| 左耳 / 右耳 | `ears.leading`（左耳小字）、`ears.tag`（右耳标签，可带颜色）、`ears.phase`（最右小字） | 各一行，放不下就中间截断 |
| 说明行 | `popup[]`：每行 `label` + `text`，`lines` 1–4，`tone` 5 种 | 最多 4 行；宽 440pt、高 ≤200pt |

## 3. 展开态（鼠标悬停）

| 格子 | 字段 | 放得下 |
|---|---|---|
| 左耳 | 同收起态左翼（计时照旧滚动）+ `ears.leading` | —— |
| 右耳 | `ears.tag`、`ears.phase`；看过后可换成 `ears.tagSeen` | 各一行 |
| 正文 | `body[]`，≤8 块，每块二选一：**分节** `section` 或**数字条** `stats` | 总高 ≤470pt，超出部分看不到 |

| 分节里的条目（6 种，固定） | `para` 一句话：13pt，**最多 2 行**（宽约 470pt，约 70 个汉字） | 超出截断 |

## 4. 面板（点一下刘海）

面板是照许愿柳的「会话 / 轮次」做的。非会话型的来源放进来会显示成「还没有标签」「这个会话还没有记录下来的轮次」（09-19 实拍）。

| 格子 | 字段 | 放得下 |
|---|---|---|
| 顶上标签 | 登记的 `name`；标题用 `nouns.recentHistory` | —— |
| 左栏列表 | 每个活动一行：`detail.listTitle`（一行）+ `group.name · 多久前`，圆点 `detail.dot` / `dotSeen` | 开着的平铺；「今天关闭 N」「更早 N」两行折叠 |
| 左栏标题的名词 | 登记时的 `nouns`：`activities`（会话）/ `history`（轮次）/ `recentHistory`（最近的轮次）/ `noTag`（还没有标签） | 登记时可换，不改 lintel |
| 右栏 | `detail.history[]`（≤500，新→旧）：`at`、`tag`、`badge`、`duration`、`lines[]`（label + text，默认 2 行，`expandable` 可点开）；`detail.live`（进行中的一轮） | 可滚动 |
| 左下图表 | `detail.chart`：柱（≤500）、图例（≤12）、一句 `headline` | —— |
| 底部数字条 | `detail.stats[]`（≤8） | 一行 |

| 候选 | 为什么会要 | 谁提过 |

| 右翼旁边的小数字 | 「为什么改 + 改了几处」「最大的落差 + 一共几个」 | 作者 09-18 分镜 ③；AWT 09-19 新设计 |

## 6. 对照 AWT 09-19 的新设计（`awt-loop/docs/specs/2026-09-19-awt-overhaul-design.md` 与设计会话 13:05 那一轮）

| 要显示的 | 现在能直接放吗 |
|---|---|
| 刘海上「当前最大的落差」一句 | 能：右翼 `label`，约 6 个汉字 |
| 落差个数 | 只能写进那句字里；做成小数字要 lintel 加格子（§5） |
| 弹出两行说明 | 能：`popup` |
| 三行：你要读者带走的 / 读者读成了 / 稿子替你加的 | 能：三个 `section` 各一条 `para`（每句 ≤2 行）；要并排对照、高亮落差，得加对照条目（§5） |
| 多个模拟读者各自读成了什么 | 能：每个读者一个 `section` |
| 按段落或按读者浏览 | 不能：面板是会话型的（§4、§5） |
| 不压过许愿柳 | 能：不用 `waiting`；`attention` 只给真要你回应的事件 |

## 7. 来源程序自己要守的几条（lintel 不管，但不守就会难看）

1. 一个来源尽量只写**一个**活动；多件事放进它的 `body` 分节，不要拆成多个活动。
2. `rank: waiting` 只给真要你回应的事；它会排在所有来源前面。
3. `attention` 只给「刚发生、要你看」的事件；一直在的状态不要标，否则每次重扫都会把刘海拉开。
4. 右翼那句写结论，不写类别名（写「被读成认输」，不写「触发源」）；约 6 个汉字，超了会被截断。
5. 展开态要有一句人话说「这是什么事、要你做什么」，不能只有数字。
